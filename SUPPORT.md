# Support

SCH is maintained by a small team on a best-effort basis.

- **Questions / usage help**: open a thread in
  [GitHub Discussions](https://github.com/c-daniele/sch/discussions).
- **Bugs**: open a [GitHub issue](https://github.com/c-daniele/sch/issues/new/choose)
  using the bug template.
- **Security vulnerabilities**: never in public — see
  [SECURITY.md](SECURITY.md).

There is no real-time chat or SLA. Response times depend on maintainer
availability; be patient and include enough detail (exact command, output,
environment) that someone can reproduce your problem.

Note: SCH creates billable AWS resources. For cost questions, start with the
[Before you deploy](README.md#before-you-deploy-costs-and-security) section of the README and
[Lifecycle and costs](docs/deploy.md#lifecycle-and-costs); `sch destroy` tears a deployment down.
